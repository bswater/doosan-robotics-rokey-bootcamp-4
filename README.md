# 두산로보틱스 로키부트캠프 4기

2025년 두산로보틱스 ROKEY 부트캠프에서 진행한 협동로봇·자율주행 프로젝트를 정리했습니다. 협동로봇으로 책과 물품을 다루는 작업을 구현하고, 이동로봇에서는 카메라 인식 결과를 주행과 서비스 동작에 연결했습니다.

## 협동 1 · 사서 보조 및 독서 지원 로봇

협동로봇 한 대가 책 반출입, 페이지 넘기기, 청소를 수행하도록 작업을 구성했습니다. 책장과 받침대, 도구함 등 로봇이 책과 도구에 접근하는 데 필요한 작업 환경을 설계하고 구성했습니다.

## 협동 2 · 음성·영상 기반 물품 정리

사용자의 음성 명령과 카메라 영상에서 정리할 물품을 식별하고, 로봇팔로 집어 지정 위치에 놓는 프로젝트입니다. 음성 처리 프로그래밍과 인식용 데이터 수집·학습에 참여했습니다.

- [음성 처리](./Cooperation2/RF_Robot_Arm/voice_processing)에서 호출어 감지와 음성 인식을 확인할 수 있습니다.
- [물체 인식](./Cooperation2/RF_Robot_Arm/object_detection), [ArUco 검출](./Cooperation2/RF_Robot_Arm/aruco_detection), [로봇팔 제어](./Cooperation2/RF_Robot_Arm/robot_control)는 [통합 launch 파일](./Cooperation2/RF_Robot_Arm/launch/full_system.launch.py)과 함께 볼 수 있습니다.

## 협동 3 1차 · 자율주행 시뮬레이션

모의 도로에서 차선을 따라 주행하면서 신호등과 정지선을 판단하고, 표지판이 있는 교차로를 통과하며, 사람과 다른 차량에 대응하도록 구성했습니다. [협동 3 실습 자료](./Cooperation3)에서 TurtleBot3 관련 압축 파일을 확인할 수 있습니다.

## 디지털 트윈 기반 서비스 로봇 운영

차선 추종 중 신호등과 차단봉을 인식하고, 작업 지점에서 ArUco 마커를 인식하는 흐름을 구성했습니다. 신호등 인식을 담당해 카메라 영상의 관심 영역을 HSV로 변환하고, 색상 마스크와 후보 영역 조건으로 신호를 판별했습니다. 반사광이 신호로 검출되는 문제는 영상 처리 조건과 판정 로직을 조정해 개선했습니다.

## 무인 박물관 보조 로봇

TurtleBot4 두 대가 도슨트와 순찰 역할을 나눠 수행하는 ROS 2 시스템입니다. 바코드로 예약 정보를 읽고 PyQt 대시보드와 SQLite로 관람 정보를 관리했습니다. 안내 로봇은 관람객을 작품 위치로 안내하고, 순찰 로봇은 순찰과 기념품 전달을 담당했습니다. 저는 **안내 로봇 제어**를 맡아 좌표 이동과 전시 안내 흐름을 구현했습니다.
